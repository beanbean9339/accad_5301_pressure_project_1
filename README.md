# Pressure Project 1 - TouchDesigner

This repository contains the files for my **Pressure Project 1** created in TouchDesigner for **ACCAD 5301** at The Ohio State University.

The project explores interactive visuals, audio, and 3D elements using TouchDesigner. The repository includes the main TouchDesigner project file along with the audio, music, and image assets used in the project.

## Project Information

- **Course:** ACCAD 5301
- **Project:** Pressure Project 1
- **Software:** TouchDesigner
- **Creator:** Isabella Lo
- **Institution:** The Ohio State University

## Files

- `Pressure_Project_1.toe` - Main TouchDesigner project file
- `Audio/` - Audio and music files used in the project
- `Images/` - Image files and visual assets used in the project
- Additional project assets needed for the TouchDesigner project

## How to Use

1. Download or clone this repository.
2. Keep the files and folders in their original structure.
3. Open the `.toe` file in **TouchDesigner**.
4. If TouchDesigner cannot find an asset, make sure the `Audio` and `Images` folders are located in the same directory as the project file.
5. The project should then open with the included assets.

## Tutorials & References

I used several TouchDesigner tutorials as references while developing this project. These tutorials helped me learn different techniques that I then incorporated and adapted into my project.

### 1. Organic Creature

**[TD Drop #25] Organic Creature - TouchDesigner Tutorial**  
By Pao Olea

https://www.youtube.com/watch?v=_JAKbwCQkcc

This tutorial was used as a reference for creating and manipulating the organic creature visuals in the project.

### 2. Audio Reactive Visuals

**Audio Reactive Visuals - TouchDesigner Tutorial**

https://www.youtube.com/watch?v=JFiw01mQabE

This tutorial was used as a reference for connecting audio information to visual elements and creating visuals that respond to the music.

### 3. 3D Text

**3D Text - TouchDesigner Tutorial**

https://www.youtube.com/watch?v=n7jNNIa9VdM

This tutorial was used as a reference for creating and working with 3D text elements in TouchDesigner.

The tutorials were used as learning references and starting points. The techniques were adapted and combined with my own project structure, visuals, audio, and creative decisions.
